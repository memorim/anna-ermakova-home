# Анна Ермакова — Дом для вас

Утверждённая вторая концепция. Статический адаптивный лендинг без сборки и зависимостей.

Публикация: Render Static Site, ветка `main`, каталог `public`, команда `echo static`.

Marquiz: `6ac62af87318ce000e678108` («Общий лендинг. ЖК»). Первый ответ на странице синхронизирован между двумя блоками и передаётся в нативный Marquiz через проверенное окно и origin. Остальные вопросы, контакты и отправку обрабатывает Marquiz. При блокировке скрипта кнопка открывает публичную страницу квиза.

В Marquiz → Интеграции → Свой код подключён `/marquiz-theme.js` с сайта. Он оформляет нативный квиз, добавляет логотип КВИКО и принимает первый ответ. Заявки не сохраняются на лендинге.

Фото: материалы канала https://max.ru/ermakova_rieltor из утверждённой концепции. Логотип извлечён из брендбука заказчика. Текст цен сохранён из утверждённого макета; актуальность предложений подтверждает заказчик.

Локально: `python -m http.server 8097 --directory public`. Проверка: `node --test tests/quiz.test.cjs`.
