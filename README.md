# Дом для вас
Адаптивный лендинг Анны Ермаковой. Render публикует каталог public из main. На странице одна встроенная форма Marquiz. Нижняя кнопка возвращает к текущему вопросу. Ответы и контактные данные обрабатывает Marquiz.
В разделе «Интеграции → Свой код» квиза подключён marquiz-theme.js с сайта. Фотографии и логотип предоставлены заказчиком.
Проверка: node --test tests/quiz.test.cjs
